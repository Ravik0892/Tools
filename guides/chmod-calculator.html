The Linux Chmod Permissions Calculator simplifies file permission management on Linux, UNIX, macOS, and POSIX servers. It translates interactive permission checkboxes into numeric octal values (0755, 0644) and symbolic strings (-rwxr-xr-x) with live terminal command generation.

The Permission Math (Base 8)

Each scope receives a sum of three binary bits:

  • Read (r) = 4: Allows viewing the file contents or listing directory files.
  • Write (w) = 2: Allows modifying, appending, or deleting files.
  • Execute (x) = 1: Allows running a program/script or entering a directory.
Standard Server Presets Best Practices
  • 644 (Web Files): Owner can read/write; everyone else read-only. Standard for HTML, CSS, JS.
  • 755 (Web Folders & Scripts): Owner full access; Group and Others read and enter.
  • 600 (SSH Keys): Only the owner has access. Mandatory for ~/.ssh/id_rsa.
