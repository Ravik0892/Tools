Frequently Asked Questions (FAQ)

Is it safe to generate RSA private keys in a web browser?

Yes, on OmniTool Hub. The Web Crypto API uses OS-level entropy pools (`/dev/urandom` or Windows CryptoAPI). The private key never leaves your device memory.

What is the difference between PKCS#1 and PKCS#8 PEM formats?

PKCS#1 begins with `-----BEGIN RSA PRIVATE KEY-----` and only supports RSA. PKCS#8 begins with `-----BEGIN PRIVATE KEY-----` and is the modern standard supported by all programming languages.

Can I use these keys for SSH login?

Yes. You can export the public key in OpenSSH format (`ssh-rsa ...`) and the private key for your `.ssh/id_rsa` file.

Why does 4096-bit key generation take slightly longer?

Generating 4096-bit keys requires finding two 2048-bit probabilistic prime numbers and running Rabin-Miller primality tests, ensuring maximum mathematical strength.
