## ⚡ How to Deploy on Cloudflare Pages for `worldsneed.com`

You can deploy this in **under 2 minutes** using Cloudflare Pages:

### Step 1: In your Cloudflare Dashboard
1. Go to **Workers & Pages** ➔ Click **Create application** ➔ Click **Pages** ➔ **Connect to Git**.
2. Select your repository: **`Ravik0892/Tools`**.

### Step 2: Set Build Settings
* **Project Name**: `worldsneed-portal` (or `worldsneed-home`)
* **Production branch**: `main`
* **Framework preset**: `None`
* **Build command**: *(leave empty)*
* **Build output directory**: *(leave empty)*
* **Root directory (advanced)**:
  ```text
  worldsneed-landing-page
  ```
  *(This tells Cloudflare to serve this specific folder for `worldsneed.com`!)*

### Step 3: Connect Your Domain (`worldsneed.com`)
1. Once deployed, click on the project ➔ Go to the **Custom domains** tab.
2. Click **Set up a custom domain**.
3. Type:
   ```text
   worldsneed.com
   ```
4. Click **Continue** ➔ Click **Activate domain**.
5. Repeat to add `www.worldsneed.com` if desired!
