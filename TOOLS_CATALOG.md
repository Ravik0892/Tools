### 1.3 `jwt-decoder` — JWT Token Decoder & Expiry Inspector
*   **Hash Route**: `#tool/jwt-decoder`
*   **Core Purpose**: Decodes JSON Web Tokens into inspection panels without sending tokens to any external server.
*   **Key Capabilities**:
    *   **Header Inspection**: Algorithm (`alg`: HS256, RS256, etc.) and token type (`typ`).
    *   **Payload Inspection**: Beautified JSON view of user ID (`sub`), roles, permissions, scopes, and custom claims.
    *   **Signature Verification Status**: Displays raw cryptographic signature bytes.
    *   **Automated Expiration Diagnostics**: Converts `exp` (expiration) and `iat` (issued at) epoch timestamps into human-readable local dates; warns in bright red if token is already expired.

### 1.4 `crypto-suite` — Cryptography & Security Suite
*   **Hash Route**: `#tool/crypto-suite`
*   **Direct Sub-Tabs**:
    1.  **Hashes (`#hash-generator`)**:
        *   Computes MD5, SHA-1, SHA-256, and SHA-512 hashes simultaneously in real time.

    2.  **AES Cipher (`#aes-crypto`)**:
        *   Symmetric authenticated encryption using AES-256-GCM.

    3.  **Asymmetric Keys (`#rsa-generator`)**:
        *   Generates 2048-bit or 4096-bit RSA-OAEP / RSA-PSS key pairs using browser `window.crypto.subtle`.
        *   Exports formatted PEM strings (`-----BEGIN PUBLIC KEY-----` and `-----BEGIN PRIVATE KEY-----`).

### 1.5 `pii-anonymizer` — Client-Side PII Masker & Anonymizer
*   **Hash Route**: `#tool/pii-anonymizer`
*   **Core Purpose**: Scans log files, database dumps, and texts for Personally Identifiable Information (PII) to comply with GDPR, HIPAA, and privacy standards.
*   **Detection Modules**:
    *   Email Addresses
    *   Phone Numbers (US, International, E.164 formats)
    *   IPv4 & IPv6 Addresses
    *   Credit Card Numbers (Visa, Mastercard, Amex, Discover with Luhn check)
    *   Social Security Numbers (SSN)
    *   API Secrets, Bearer Tokens & Private Keys
*   **Masking Strategies**:
    *   `Redact`: Replaces sensitive tokens with clean placeholders like `[EMAIL_REDACTED]`.
    *   `Hash`: Generates deterministic SHA-256 hashes so relational linkages remain auditable.
    *   `Mask`: Obfuscates values with asterisk characters (e.g. `4111********1111`).

## 🤖 Instructions for AI Agents & Developers

When extending or maintaining OmniTool Hub:
1.  **Adding a New Tool**:
    *   Create tool implementation under `tools/<tool-id>.js`.
    *   Export default object implementing `id`, `name`, `renderUI()`, `init(container, appInstance)`, and optional `cleanup()`.
    *   Register the tool in `app.js` under `this.tools`, `this.toolKeywords`, `this.toolBenefits`, `this.toolFeatures`, and `this.toolWorkflows`.
    *   The tool will **automatically** appear in Admin Settings (`👁️ Tool Visibility` and `🔒 Monetization Tiers`) without additional admin code.
2.  **Tool Redirection Pattern**:
    *   If a tool is an embedded subtab of a larger suite, register it in `app.js` under `this.toolRedirects`:
        ```javascript
        "new-sub-tool": { suiteId: "parent-suite", subtab: "target-subtab" }
        ```
3.  **Client-Side Privacy Guarantee**:
    *   All data operations must execute strictly in-memory (using Web Workers, WebCrypto, Canvas, or WebAssembly).
    *   Never send user file contents or inputs to third-party endpoints.
