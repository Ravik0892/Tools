Frequently Asked Questions (FAQ)

What is the difference between linear, radial, and conic gradients in CSS?

Linear gradients transition colors along a straight directional vector defined by an angle or side keyword. Radial gradients emanate outwards in concentric circular or elliptical waves from a central origin. Conic gradients rotate color transitions around a center pivot point like a clock hand, making them ideal for pie charts and rainbow border animations.

How do color stop percentages work in CSS gradients?

Color stops define where each transition begins and ends along the gradient axis. For example, in linear-gradient(90deg, red 0%, blue 100%), red begins at the far left and blends continuously into blue at the far right. Placing two color stops at the exact same percentage (e.g. red 50%, blue 50%) creates a razor-sharp hard color split without any blur.

Are CSS gradients faster than background images?

Yes! CSS gradients require zero network bandwidth, zero HTTP requests, and scale infinitely to retina and 4K displays without resolution pixelation. Browsers render them on GPU memory, resulting in instant First Contentful Paint (FCP).

Can I animate CSS gradients directly with CSS transitions?

Because background-image gradients are images rather than numbers, standard CSS cannot interpolate between two gradient values directly. However, you can achieve smooth 60fps animations by animating background-position across an oversized background-size (e.g. 200% 200%), or by animating custom CSS @property color variables.
