Frequently Asked Questions (FAQ)

Will compressing a PDF make the text blurry?

No. Vector fonts and digital text remain razor sharp at any zoom level because they are mathematical vector paths. Only embedded raster images are optimized.

How does OmniTool Hub compress PDFs without uploading them?

The engine uses HTML5 Canvas and WebAssembly to downsample and re-compress embedded raster streams directly inside your browser’s memory.

Can I see the resulting file size before downloading?

Yes. The interface calculates and displays the new file size and percentage reduction immediately after processing.

Can encrypted or password-protected PDFs be compressed?

You must provide the password to decrypt the file in memory first, after which it can be optimized and re-saved.
