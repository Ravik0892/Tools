# 🎨 OmniTool Hub - Social Media Branding Assets & Exporter Kit

This directory contains vector (`.svg`) and high-resolution exportable graphics for **OmniTool Hub** across all major social media platforms.

---

## ⚡ Interactive Exporter Features

Open **[`index.html`](file:///f:/Tools%20website/social_media_assets/index.html)** in your browser to access the live exporter tools:

1. **Background Style Selector**:
   - 🌙 **Dark Glow**: Rich neon magenta-cyan glow on dark background (Default theme).
   - ✨ **Transparent Cutout**: Strips background layers for **100% transparent PNG logo cutouts** (great for overlays, watermarks, photos, and post graphics).
   - ☀️ **White Theme**: Solid white background mode for light theme social media posts.

2. **Resolution Scale Multiplier**:
   - **1x Standard**: Standard resolution export.
   - **2x HD Retina**: Double resolution (Recommended for high-DPI displays).
   - **4x Ultra HD 4K**: Ultra high-res output for crisp printing and large displays.
