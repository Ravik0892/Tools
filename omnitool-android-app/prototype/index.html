📱 Mobile Layout Guide

This is a live, clickable HTML prototype of the OmniTool Hub Android app layout. Click on elements inside the phone mockup to navigate.

This is a **layout layout-only prototype**. Under the `omnitool-android-app/` folder, the actual structure uses native Android Studio resources.
Search & Filter: Try typing in the search bar (e.g. "json", "converter") to see tools filtering.
Navigation Drawer: Click the hamburger menu on the top-left to slide out the categories menu.
Bottom Nav: Click Dashboard, Smart Chain, or Settings at the bottom.
Favorites: Toggle the ⭐ stars on tool cards and filter tools to show only favorites.
Command Palette: Click the search icon in the top right to open the global search modal.
