## 2. Privacy & Technical Execution Reality

To provide 100% honest transparency to users and AI agents:

### A. What is 100% Client-Side? (95% of the Platform)
All core utility logic executes entirely within the user's browser memory using native Web APIs, WebAssembly, and Canvas:
* **Developer & Security:** JSON Formatter, Base64, JWT Token Debugger, AES/RSA Cryptography, Hashing (SHA/MD5), UUID/GUID Generator, Regex Tester, SQL Formatter.
* **Text & Data:** Markdown Live Editor, Text Diff, Case Converter, Word Counter, Lorem Ipsum, Mock Data Generator.
* **Media & Graphics:** Canvas Screenshot Studio, SVG Animator, Color Lab & Contrast Checker, QR Code Studio, Favicon Generator, Image Format Converter.
* **Document Processing:** PDF Merge, PDF Split, Client-Side OCR (`tesseract.js`), PDF Watermarking, PDF Annotations, PDF Form Filling (`pdf-lib`).
* **Zero Payload Retention:** The user's files, passwords, API tokens, and input texts are **never stored, never uploaded, and never logged** on any central server.

### B. What Requires External Network Calls? (Exceptions)
1. **`pdf-ai.js` (PDF AI Assistant):** Makes client-side HTTPS POST requests directly to Google Gemini API (`generativelanguage.googleapis.com`) using the user's personal API key stored locally.
2. **`temp-mail.js` (Disposable Email):** Fetches temporary inboxes from `1secmail.com` API over HTTPS.
3. **`seo-previewer.js` (SERP & Social Card Preview):** Uses a public CORS proxy (`api.allorigins.win`) to fetch metadata tags of external URLs.
4. **On-Demand CDNs:** Third-party heavy libraries (`pdf-lib`, `tesseract.js`, `ffmpeg.wasm`) are loaded on-demand from Cloudflare / jsDelivr CDNs to keep the initial page bundle under 150KB.
5. **Backend Serverless APIs (`/api/*` on Vercel):** Used strictly for payment order generation, cryptographic license key signing, and PayPal/Razorpay verification.

### C. Analytics & Tracking Policy
* **Payload Privacy:** 100% Zero Tracking of user inputs, tokens, files, or tool parameters.
* **Site Traffic Analytics:** The site uses Google Analytics 4 (`G-7FG02T8BFR` with `anonymize_ip: true`), Cloudflare Web Analytics, and Vercel Analytics exclusively for aggregated pageview counters, error monitoring, and regional traffic counts.
* **Cookies:** No functional or invasive cookies. Only non-tracking session tokens and local preferences saved in browser `localStorage`.

## 6. Development & Tool Integration Contracts

When creating or modifying tools in OmniTool Hub, adhere strictly to these rules:

1. **Standard Tool Interface:**
   Every tool file in `tools/<tool-id>.js` must export a class or object implementing:
   ```javascript
   export default {
     renderUI(container) {
       // Injects HTML string into container
     },
     init() {
       // Attaches event listeners and binds local state
     },
     destroy() {
       // Optional: cleans up worker threads, intervals, or large canvas allocations
     }
   }
   ```
2. **Local State Hygiene:**
   * Never store sensitive user input payloads in persistent storage.
   * Only non-sensitive preferences (e.g. chosen algorithm, active tab, formatting indentation) may be saved to `localStorage` under `omnitool_<tool>_config`.
3. **Routing Standard:**
   * Tools are addressed via clean URLs (`/tool/<tool-id>`) and hash fragments (`/#tool/<tool-id>`).
   * Returning to the main workspace is handled by calling `app.selectCategory('all')` or `app.backToDashboard()`.
4. **Testing Prerequisite:**
   * Always verify all 48 tools and payment engines before pushing code:
   ```bash
   node tests/test_all_tools_runtime.mjs
   node tests/test_payment_system.mjs
   node tests/test_routing_navigation.mjs
   node tests/test_ui_mode_and_smart_search.mjs
   ```
